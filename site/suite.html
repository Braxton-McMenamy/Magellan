Team suite

Everyone's work, checked together.

Each person's change can pass on its own and still break when the two meet: one adds a required parameter, the other adds a call the old way. Connect your team's repository to see what everyone is changing right now, and the problems that only the combination has, before anyone merges.

Connect a repository

About the token

A public repository needs none: the page reads it the way anyone can, about once every 90 seconds (GitHub allows 60 requests an hour without one). A token lets it read a private repository and look every 15 seconds.

Make a fine-grained token at GitHub → Settings → Developer settings, for only this repository, with Contents: read-only. It stays in this browser tab (gone when you close it, or press Forget) and is sent only to api.github.com.

How your team shares

Nobody commits or pushes a branch. Each person publishes their working tree to refs/wip/<name> on the same repository:

$ magellan-lite share

or, in VS Code, turns on Magellan Lite: Share On Save. Everyone who can read the repository can read what's shared, so on a public repository it is public.

The same check on the command line: magellan-lite team.
