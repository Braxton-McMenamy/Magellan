A pre-commit check for Python

Know what your change breaks before you commit it.

Magellan Lite maps your code from its syntax trees, finds exactly what a change touched, and runs a checklist built from real software disasters. One verdict: ok review block.

How it works

  1. 1 Map

    Every function, method, class and constant, named stably and hashed from its syntax tree. Reformatting, moving code or switching line endings is never a change.

  2. 2 Diff

    Compare with the last commit (or any baseline): what was added, removed, or had its signature, body or value changed.

  3. 3 Check

    Run the checklist on exactly what changed, so old problems elsewhere stay quiet. Each rule comes from a failure that really happened.
