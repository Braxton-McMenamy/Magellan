# The whole team, live

The **Team suite** on the Magellan Lite website reads your repository's shared work in
progress and checks everyone's together: each person, every pair that breaks only when
combined, and one map with each person's changes in their own colour.

This extension finds your workspace's GitHub repository from its git remote, so **Open the
Team suite** lands already connected. Nothing to type.

Turn on **Share On Save** and your work is shared as you go (at most every 15 seconds), so
the suite follows along.
